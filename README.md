# 클로드 코드(Claude Code) 멀티에이전트 팀 자동화 완성 가이드

> **키워드**: Claude Code 멀티에이전트, AI 팀 자동화, TMUX 멀티에이전트, Claude Code Remote Control, AI 에이전트 팀 구성, 1인 개발 AI 팀, AI 개발 생산성, Claude Code WSL2, 스마트폰 AI 원격 제어, MCP 서버 연동, Redis 상태 공유, GitHub Actions 자동화, LLMWiki 기억하는 AI 팀

---

## 이런 분들에게 추천합니다

- **1인 개발자** — 혼자서 기획·개발·리뷰를 AI 팀에 맡기고 싶은 분
- **Claude Code 입문자** — 단순 질답을 넘어 AI를 팀으로 운용하고 싶은 분
- **생산성 자동화에 관심 있는 개발자** — AI 에이전트로 반복 작업을 없애고 싶은 분
- **원격 근무자·이동이 많은 개발자** — 스마트폰으로 AI 팀을 지휘하고 싶은 분
- **AI 자동화 파이프라인 구축에 관심 있는 분** — GitHub Actions, MCP, Redis 같은 외부 도구와 AI를 연결하고 싶은 분

> **사전 지식**: 터미널 기본 명령어(ls, cd, mkdir) 수준이면 충분합니다. Ubuntu·Linux 경험이 없어도 WSL2 설치부터 차근차근 안내합니다.

## 이 책은 무엇인가요?

이 책은 **Claude Code와 TMUX를 조합해 멀티에이전트 AI 팀을 구성하고, Remote-Control로 어디서든 팀을 지휘하는 방법**을 다룬 실전 가이드입니다. AI 에이전트 하나를 쓰는 것에서 벗어나, 6명의 AI 에이전트가 동시에 협업하는 팀 자동화 환경을 직접 만듭니다.

보통 AI를 이렇게 씁니다.

```
나 → Claude에게 질문 → 답변 → 또 질문 → ...
```

이 책은 이걸 가능하게 합니다.

```
나 (스마트폰으로 원격 지시)
  ↓
팀장 AI (Claude Code) → 기획자 AI, 개발자 AI, 리뷰어 AI에게 동시에 배분
```

- **Claude Code** — 터미널에서 파일을 직접 읽고 쓰는 AI 에이전트
- **TMUX** — 화면을 여러 칸으로 나눠 멀티에이전트를 동시에 실행
- **Remote-Control** — 스마트폰에서 내 컴퓨터의 AI 팀을 원격 지휘

---

## 멀티에이전트를 이렇게 활용합니다

**출근길 지하철에서 AI 팀에 일을 시킨다**
스마트폰 Remote-Control로 "결제 모듈 버그 수정해줘"라고 보내면, 사무실에 도착했을 때 AI 에이전트가 이미 코드를 고쳐놓고 있습니다.

**멀티에이전트 6가지 일이 동시에 진행된다**
기획자 AI가 설계 문서를 쓰는 동안, 개발자 AI가 코드를 짜고, 리뷰어 AI가 품질을 검토합니다. AI 팀 자동화로 순서를 기다릴 필요가 없습니다.

**컨텍스트가 끊겨도 AI 팀 작업이 이어진다**
새 세션을 시작해도 AI 에이전트가 이전 작업 맥락을 파일에서 불러옵니다. "아까 어디까지 했더라"가 사라집니다. 코드 작성 → 테스트 → 리뷰 → PR 생성까지 한 흐름으로 이어지고, 1인 개발자도 최종 승인만 하면 됩니다.

## Claude Code 멀티에이전트, 어떻게 가능한가요?

세 가지 핵심 기술을 조합합니다.

**TMUX — Claude Code 에이전트를 여러 명으로 만든다**
터미널 화면을 6칸으로 나누고, 각 칸에서 Claude Code를 독립적으로 실행합니다. 멀티에이전트 각자가 다른 역할을 맡아 동시에 일합니다.

**CLAUDE.md — AI 에이전트에게 역할을 부여한다**
각 AI 에이전트가 시작할 때 읽는 역할 정의 파일입니다. "너는 개발자야, 설계는 네 역할이 아니야"처럼 에이전트 역할 경계를 명확히 합니다.

**Remote-Control — 스마트폰으로 AI 팀을 원격 제어한다**
내 컴퓨터에서 실행 중인 Claude Code 팀에게 스마트폰으로 연결합니다. 코드와 파일은 절대 클라우드로 나가지 않고, 통신 경로만 인터넷을 씁니다.

## 책 구성 (Claude Code 멀티에이전트 완전 정복 로드맵)

각 장은 이전 장 위에 쌓이는 구조입니다. 2장에서 기반을 만들고, 3장에서 네이티브 멀티에이전트를 익힌 뒤, 4~6장에서 TMUX 기반 AI 팀을 구성하고, 7~9장에서 실전 자동화 수준으로 끌어올립니다. 전체 11장, 57개 절로 구성됩니다.

**1장. 들어가며**
왜 AI를 혼자 쓰면 안 되는지, 멀티에이전트 팀이 왜 필요한지 설명합니다. 전체 아키텍처를 미리 보고, 기억을 공유하는 AI 팀(LLMWiki)이라는 이 책의 지향점을 파악합니다.

**2장. 개발 환경 구축 — Claude, TMUX, Git**
WSL2·Ubuntu·macOS 호스트에 Claude Code와 TMUX를 직접 설치하고 인증까지 마칩니다. 마지막으로 Git 설치와 GitHub 연동·협업 사용법을 더해, AI 팀이 버전 관리까지 다루는 기반 환경을 만듭니다.

**3장. 네이티브 Claude Code 멀티에이전트**
한 세션 안에서 Claude Code가 스스로 서브에이전트를 부리는 네이티브 방식을 익힙니다. 역할별 Subagent 설계와 병렬 실행, Skills 작성·Hooks 자동 검증·Git Worktree 병렬 개발로 강화한 뒤, 네이티브의 한계를 짚어 다음 장의 TMUX 팀으로 자연스럽게 넘어갑니다.

**4장. Claude Code와 TMUX로 멀티에이전트 구성**
TMUX 화면을 6칸으로 나누고 각 칸에 Claude Code를 실행합니다. CLAUDE.md로 팀원별 역할을 정의하고, 셋업 스크립트로 원클릭 팀 환경을 구성합니다.

**5장. Claude Code Remote-Control 기능 설정 및 사용**
Remote-Control을 활성화해 외부에서 로컬 Claude Code 세션에 접근하는 방법을 설정합니다. 서버 모드, 세션 이름 관리, stream-json, 보안 설정을 살펴봅니다.

**6장. 휴대폰 Claude 앱에서 Remote-Control 사용**
스마트폰 Claude 앱으로 PC의 AI 팀에 접속합니다. QR 코드 연결, 세션 목록 확인, 도구 승인, 푸시 알림으로 작업 완료를 확인합니다.

**7장. 핵심 도구 설치 및 활용**
gstack, superpowers, gsd, RTK를 설치하고 활용합니다. 이어 MCP(Model Context Protocol)로 AI에 외부 도구를 연결하고, 멀티에이전트 환경에서 특히 유용한 MCP 도구(Memory·Sequential Thinking·Playwright·Context7 등)를 별도로 정리합니다.

**8장. 실전 팀 에이전트 운용**
팀 지시 흐름 설계, Bot Mode 활용, 업무 분담 전략을 다룹니다. gstack + GSD + Superpowers를 조합한 Triple Crown 전략과 실전 워크플로우 예시, 그리고 네이티브와 TMUX 팀을 같은 과제로 비교하는 대비 실전 예제로 팀 자동화를 완성합니다.

**9장. 고급 운용 기법**
실제 멀티에이전트 운영 사례, GitHub Actions 자동화, 컨텍스트 관리, 충돌 방지를 다룹니다. 나아가 Redis로 팀원 간 상태를 공유하는 이유와 구현, 실제 충돌 사례까지 담은 이 책에서 가장 실전적인 장입니다.

**10장. 운영 및 문제 해결**
Remote-Control 인증 오류, TMUX 세션 복구, 토큰 최적화 심화, 자동 복구를 다룹니다. 실제 운영 중 마주치는 문제를 해결합니다.

**11장. 마치며**
옵시디언 기반 LLMWiki로 팀이 기억을 쌓아가는 방향을 소개하고, AI 에이전트 기술의 발전 방향을 전망합니다.

- 1인 개발자도 기획·개발·리뷰를 AI 에이전트 팀에 분담하는 체계
