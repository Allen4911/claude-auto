## 03-3. 슬래시 명령어 기초

Claude Code를 쓰다 보면 "이 대화를 초기화하고 싶다", "지금 어떤 모델을 쓰고 있지?", "컨텍스트가 꽉 찼다는데 어떻게 하지?" 같은 순간이 생깁니다. 이런 **세션 제어**는 자연어 대화가 아니라 슬래시(`/`)로 시작하는 명령어로 합니다. 이 절에서는 가장 자주 쓰는 슬래시 명령어 여섯 가지를 익혀서 어디서든 길 잃지 않는 **제어감**을 얻습니다.

> **이 페이지 범위**: `/help` · `/clear` · `/model` · `/context` · `/config` · `/compact` — 각 명령의 역할과 언제 쓰는지. 슬래시 명령어 전체 목록은 플랫폼·플랜·환경에 따라 달라질 수 있으므로 `/help`로 현재 목록을 확인하세요.

<hr>

## 슬래시 명령어란

슬래시 명령어는 프롬프트 입력창에서 `/`로 시작하는 짧은 명령입니다. 자연어 요청과 달리 **Claude가 해석하지 않고 Claude Code가 직접 처리**합니다. 따라서 동작이 일정하고 예측 가능합니다.

```
> /help        # 슬래시 명령어 목록과 설명 표시
> /clear       # 대화 이력 초기화
> /model       # 현재 모델 확인·변경
```

> 💡 프롬프트에 `/`를 입력하면 사용 가능한 명령어 목록이 나타납니다. 키보드 위아래 화살표로 탐색하거나 글자를 입력해 필터링하고, Enter로 선택합니다.

<hr>

## `/help` — 지금 쓸 수 있는 명령 목록

모르는 것이 생겼을 때 가장 먼저 입력하는 명령입니다. 현재 Claude Code 버전에서 지원하는 슬래시 명령어 전체와 짧은 설명을 보여줍니다.

```
> /help
```

출력 예시: [검증필요: 실제 출력 형식]

```
사용 가능한 명령어:

  /help        이 도움말 표시
  /clear       대화 이력 초기화
  /model       모델 확인 및 변경
  /context     컨텍스트 사용량 확인
  /config      설정 보기·변경
  /compact     대화를 요약해 컨텍스트 압축
  /exit        Claude Code 종료
  ...
```

**언제 쓰나**: 명령어 이름이 기억나지 않을 때, 또는 이 책에 나오지 않는 기능이 있는지 확인하고 싶을 때.

<hr>

## `/clear` — 대화 이력 초기화

현재 세션의 대화 이력을 모두 지우고 빈 상태에서 다시 시작합니다. 파일은 전혀 건드리지 않습니다.

```
> /clear
✓ 대화 이력이 초기화되었습니다.

>
```

**언제 쓰나**:

- 작업 주제가 완전히 바뀔 때 — 이전 대화 맥락이 새 작업에 혼선을 줄 수 있습니다.
- Claude가 같은 맥락을 반복 참조해 엉뚱한 답변을 낼 때.
- 컨텍스트를 가볍게 유지하고 싶을 때(긴 대화 이력은 토큰을 소모합니다).

> ⚠️ **흔한 실수**: `/clear` 후에는 이전 대화 내용을 Claude가 기억하지 못합니다. "아까 말한 그 함수"처럼 이전 맥락을 참조하면 Claude가 알 수 없다고 답합니다. 중요한 내용은 `/clear` 전에 파일이나 메모로 옮겨 두세요.

**`/clear` vs. 새 세션 시작**:

| 방법 | 결과 |
|---|---|
| `/clear` | 같은 터미널·같은 디렉터리에서 빈 대화로 재시작 |
| `exit` 후 `claude` 재실행 | 완전히 새 세션 — 이전 세션 이력이 별도 저장됨 |
| `claude --continue` | 이전 세션 이력을 다시 불러와 이어가기 |

<hr>

## `/model` — 모델 확인과 변경

현재 사용 중인 Claude 모델을 확인하거나 다른 모델로 전환합니다.

```
> /model
현재 모델: claude-sonnet-5-5
```

인수 없이 `/model`을 입력하면 인터랙티브 피커가 열립니다. 목록에서 모델을 선택하고 Enter를 누르면 **새 세션의 기본값으로 영구 저장**됩니다. 현재 세션에만 적용하려면 피커에서 `s` 키를 누릅니다. 직접 지정도 가능합니다.

```
> /model claude-opus-5-5
```

**모델별 특성 간단 정리**:

| 모델 ID | 별칭 | 특성 |
|---|---|---|
| claude-fable-5-1 | fable / best | 최고 성능 추론 |
| claude-opus-5-5 | opus | 복잡한 추론·아키텍처 분석 |
| claude-sonnet-5-5 | sonnet | 속도와 품질 균형 — 일반 작업 |
| claude-haiku-4-5 | haiku | 빠르고 가벼움 — 단순 질의 |

> 💡 `/model`에서 Enter로 선택하면 다음 세션부터도 그 모델이 기본값이 됩니다. 지금 세션에서만 바꾸고 싶다면 피커에서 `s` 키를 누르세요.

**언제 쓰나**:

- 응답이 느릴 때 가볍고 빠른 모델로 내려서 빠르게 초안을 확인하고 싶을 때.
- 복잡한 리팩터링·아키텍처 분석에서 더 강력한 모델이 필요할 때.
- 팀과 같은 모델 버전을 맞춰야 할 때.

<hr>

## `/context` — 컨텍스트 사용량 확인

현재 세션에서 컨텍스트 창을 얼마나 사용했는지 컬러 그리드로 시각화해 보여줍니다. 최적화 제안과 용량 경고도 함께 표시됩니다.

```
> /context
컨텍스트 사용량: 42,300 / 200,000 토큰 (21%)
```

**언제 쓰나**:

- 응답 품질이 떨어지거나 Claude가 앞에서 한 말을 잊는 것 같을 때 — 컨텍스트가 포화 직전일 수 있습니다.
- 긴 작업 전에 여유 공간을 확인하고 싶을 때.

> 🔀 **컨텍스트 심화(연결)**: 토큰이 무엇인지, 컨텍스트 창 한계에 가까워지면 어떤 일이 생기는지는 03-7(컨텍스트 관리 기초)에서 자세히 다룹니다. 단일 세션 한계와 멀티에이전트로 넘어가는 이유도 그 절에서 설명합니다.

<hr>

## `/compact` — 대화 요약으로 컨텍스트 압축

긴 대화를 **핵심 내용으로 요약**해 컨텍스트 창의 토큰을 절약합니다. `/clear`와 달리 대화 맥락을 완전히 버리지 않고 요약본으로 압축해 남깁니다.

```
> /compact
대화를 요약합니다...
✓ 완료. 컨텍스트: 42,300 → 8,200 토큰
```

압축 후에도 Claude는 이 세션에서 어떤 파일을 수정했고 어떤 결정을 내렸는지 요약 맥락을 유지합니다.

**`/compact` vs. `/clear` 선택 기준**:

| 상황 | 권장 명령 |
|---|---|
| 같은 작업 계속 — 맥락은 유지하되 토큰만 줄이고 싶을 때 | `/compact` |
| 완전히 다른 주제로 전환할 때 | `/clear` |
| 컨텍스트가 꽉 찼고 남은 세션이 짧을 때 | `/compact` 후 이어가기 |

> ⚠️ **흔한 실수**: `/compact`를 실행하면 세부 대화 이력은 사라집니다. 나중에 "왜 이렇게 결정했지?"를 확인하고 싶다면 `/compact` 전에 중요한 결정을 파일이나 커밋 메시지에 기록해 두세요.

**언제 쓰나**:

- 대화가 수십 턴을 넘어서 응답이 느려지거나 컨텍스트 경고가 뜰 때.
- 하루치 작업을 마무리하면서 요약 상태로 세션을 저장해 두고 싶을 때.

<hr>

## `/config` — 설정 보기와 변경

Claude Code의 동작 설정을 확인하거나 조정합니다. 별칭은 `/settings`입니다.

```
> /config
```

인수 없이 실행하면 **대화형 Settings 인터페이스**가 열립니다. 테마·모델·출력 스타일 등을 메뉴에서 변경할 수 있습니다.

직접 설정을 바꾸려면 `key=value` 형식을 사용합니다(등호 필수).

```
> /config theme=dark
> /config model=sonnet
> /config thinking=false
```

지원하는 설정 항목 전체 목록은 `/config --help`로 확인합니다.

**언제 쓰나**:

- 기본 모델을 영구적으로 바꾸고 싶을 때.
- 터미널 테마(dark/light)를 전환할 때.
- 자동 승인(`autoApprove`) 같은 동작 방식을 조정할 때.

> 🔀 **CLAUDE.md(연결)**: `/config`는 Claude Code 애플리케이션 전반의 동작을 바꿉니다. 특정 프로젝트에서만 적용할 지침(코딩 규칙, 응답 언어 등)은 03-6에서 다루는 `CLAUDE.md`에 작성합니다. 두 가지는 적용 범위가 다릅니다.

<hr>

## 슬래시 명령어 한눈에 보기

자주 쓰는 명령어를 한 표로 정리합니다.

| 명령어 | 역할 | 언제 쓰나 |
|---|---|---|
| `/help` | 명령어 목록 표시 | 모르는 것이 생겼을 때 |
| `/clear` | 대화 이력 전체 삭제 | 주제 전환·혼선 방지 |
| `/model` | 모델 확인·변경 | 속도·품질 트레이드오프 조정 |
| `/context` | 토큰 사용량 확인 | 컨텍스트 포화 전 점검 |
| `/compact` | 대화 요약 압축 | 맥락 유지하며 토큰 절약 |
| `/config` | 설정 보기·변경 | 기본 모델·테마 등 조정 |
| `/exit` | Claude Code 종료 | 세션 마칠 때 |

> 💡 처음에는 `/help`와 `/clear` 두 개만 외워도 충분합니다. "막히면 `/help`, 헷갈리면 `/clear`"라는 리듬만 몸에 익히면 나머지는 필요할 때 자연스럽게 쓰게 됩니다.

<hr>

## 정리

슬래시 명령어는 Claude와의 대화가 아닌 **Claude Code 자체를 제어하는 수단**입니다. 이 절에서 익힌 여섯 가지로 세션 안에서 일어나는 대부분의 상황을 다룰 수 있습니다.

다음 03-4에서는 터미널에서 `claude`를 실행할 때 쓰는 **CLI 플래그** — `-p`(프린트 모드), `--continue`, `--resume` 등 — 를 익혀서 Claude Code를 더 다양한 방식으로 호출하는 방법으로 넘어갑니다.
