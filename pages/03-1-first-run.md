## 03-1. 첫 실행과 기본 대화 흐름

설치를 마쳤다면 이제 Claude Code를 실제로 열어 볼 차례입니다. 이 절의 목표는 하나입니다 — 터미널 한 줄로 Claude Code를 시작해 첫 대화를 나누고, 원하는 순간에 멈추거나 나갔다가 돌아오는 **기본 리듬**을 몸에 익히는 것입니다.

> **이 페이지 범위**: `claude` 명령으로 REPL 시작 → 프롬프트 입력·응답 읽기 → 작업 중단(Esc) → 세션 종료 및 재개(`--continue`·`--resume`). 파일 편집·슬래시 명령어 등 다음 단계 기술은 03-2~03-3에서 다룹니다.

아래는 이 페이지에서 익힐 전체 흐름입니다.

```
터미널에서 `claude` 실행
        │
        ▼
 인사말 / 간단한 질문 입력
        │
        ▼
 응답 읽기 — 스크롤·출력 이해
        │
        ├─ (작업 중 중단 필요) → Esc 키
        │
        ▼
 `/exit` 또는 Ctrl+D로 종료
        │
        ▼
 `claude --continue` 로 직전 세션 재개
```

<hr>

## REPL이란 — Claude Code의 대화 방식

Claude Code는 **REPL(Read–Eval–Print Loop)** 방식으로 동작합니다. REPL이란 "입력 읽기 → 처리 → 결과 출력 → 다시 입력 대기"를 반복하는 구조입니다. Python 인터프리터나 Node.js 콘솔을 써 본 적 있다면 그 감각과 거의 같습니다.

Claude Code의 REPL에서는 여러분이 자연어 문장을 입력하면 Claude가 그 의도를 파악해 코드를 읽거나 파일을 수정하거나 명령을 실행합니다. 터미널을 닫기 전까지 이 대화는 계속 이어집니다.

> 💡 "대화"라고 표현하지만 메신저 앱과 다른 점이 있습니다. Claude Code는 파일 시스템·Git·터미널을 직접 건드릴 수 있어서, 대화 한 줄이 실제 파일을 바꾸거나 명령을 실행하는 결과로 이어질 수 있습니다. 처음에는 간단한 요청으로 동작을 확인한 뒤 점점 더 큰 작업을 맡기는 것이 좋습니다.

<hr>

## Claude Code 시작하기

프로젝트 디렉터리로 이동한 뒤 `claude`를 실행합니다.

```bash
cd ~/my-project      # 작업할 디렉터리로 이동
claude               # Claude Code 시작
```

처음 실행하면 환영 메시지와 함께 입력 프롬프트가 나타납니다. [검증필요: 정확한 초기 화면 문구·레이아웃]

```
╭─────────────────────────────────────────────────────────╮
│ ✻ Welcome to Claude Code!                               │
│                                                         │
│   /help for help, /exit to quit                         │
╰─────────────────────────────────────────────────────────╯

> 
```

`>` 기호 뒤가 여러분이 입력할 프롬프트 영역입니다. 여기서부터 Claude와 대화가 시작됩니다.

> **이 페이지 범위**: 위 화면은 프로젝트 디렉터리에서 처음 실행할 때의 일반적인 모습입니다. API 키가 없거나 로그인이 되어 있지 않으면 브라우저 로그인 화면이 먼저 나옵니다. 02-3·02-4에서 인증을 마쳤다면 곧바로 프롬프트가 열립니다.

<hr>

## 첫 프롬프트 입력하기

프롬프트에 간단한 요청을 입력해 봅니다. 처음에는 파일을 건드리지 않는 질문으로 시작하는 것이 안전합니다.

```
> 이 디렉터리에 어떤 파일이 있는지 알려줘
```

Enter를 누르면 Claude가 디렉터리 구조를 파악해 대답합니다.

```
현재 디렉터리(`~/my-project`)에는 다음 파일이 있습니다:

- README.md
- src/
  - main.py
  - utils.py
- tests/
  - test_main.py

총 4개 파일, 2개 디렉터리입니다.
```

Claude가 응답하는 동안 터미널에는 Claude가 사용하는 도구(파일 읽기, 명령 실행 등)가 표시됩니다. [검증필요: 도구 표시 방식·형식]

> 💡 첫 프롬프트로 "이 코드에서 버그를 고쳐줘" 같은 큰 작업보다 "이 파일에 뭐가 있어?" 같은 읽기 전용 요청을 먼저 해 보세요. Claude의 동작 방식을 확인한 뒤 점차 권한이 필요한 작업으로 넓혀 가는 것이 좋습니다.

<hr>

## 응답 읽기 — 긴 출력 다루기

Claude의 응답이 길면 터미널 스크롤이 쭉 올라갑니다. 몇 가지 방법으로 편하게 읽을 수 있습니다.

**터미널 스크롤**: 대부분의 터미널에서 `Shift+PageUp` / `Shift+PageDown`으로 스크롤합니다. Mac 터미널은 트랙패드 스크롤로도 됩니다.

**응답이 끝나기 전 읽기**: Claude가 출력을 생성하는 중에도 위로 스크롤해 읽을 수 있습니다. 출력이 완전히 끝나지 않았어도 내용은 이미 화면에 있습니다.

**코드 블록 확인**: Claude가 파일을 수정할 때는 변경 전·후를 diff 형식으로 보여줍니다. `-`로 시작하는 줄은 삭제된 내용, `+`로 시작하는 줄은 추가된 내용입니다. 이 표시를 읽는 법은 03-2(파일 편집 워크플로우)에서 자세히 다룹니다.

> 🔀 **컨텍스트 관리(연결)**: 대화가 길어질수록 Claude의 컨텍스트 창이 쌓입니다. `/clear`로 대화를 초기화하거나 `/compact`로 요약하는 방법은 03-7에서 다룹니다.

<hr>

## 작업 중단하기 — Esc 키

Claude가 파일 수정이나 명령 실행 같은 작업을 진행 중일 때 멈추고 싶다면 **Esc 키**를 누릅니다. Esc는 현재 응답 또는 도구 호출을 **즉시 중단**합니다. 지금까지 완료된 작업은 그대로 유지됩니다.

```
Claude가 작업 중...
[Esc]                 # Esc 키 입력 — 즉시 중단
✗ 작업이 중단되었습니다.

>                     # 프롬프트로 돌아옴
```

중단 후에는 프롬프트가 다시 나타납니다. 여기서 다음 지시를 바로 입력할 수 있습니다.

> 💡 **Ctrl+C와의 차이**: Ctrl+C도 작업을 중단하지만 동작이 다릅니다. 아무것도 실행 중이지 않을 때 첫 번째 Ctrl+C는 입력창을 지우고, 두 번째 Ctrl+C는 Claude Code를 종료합니다. 작업 중 멈추려면 Esc를, 종료하려면 `/exit`를 사용하세요.

> ⚠️ **흔한 실수**: Esc로 중단하더라도 **이미 실행된 도구 결과는 되돌릴 수 없습니다**. 예를 들어 파일 5개 중 3개를 수정한 뒤 중단하면 3개는 이미 바뀐 상태입니다. `git diff`로 변경 내용을 확인하고, 원하지 않는 변경은 `git checkout` 또는 `git restore`로 되돌리세요.

**중단이 유용한 상황**:
- Claude가 예상보다 훨씬 큰 범위로 작업을 시작했을 때
- 잘못된 방향으로 가고 있다고 판단될 때
- 먼저 결과를 확인하고 나서 계속할지 결정하고 싶을 때

<hr>

## 세션 종료하기

대화를 마치려면 두 가지 방법을 쓸 수 있습니다.

**슬래시 명령어**:

```
> /exit
```

**키보드 단축키**: `Ctrl+D`를 두 번 누르면 종료됩니다. 첫 번째 누름은 확인 힌트를 표시하고, 800ms 안에 두 번째를 누르면 종료됩니다. 프롬프트에 텍스트가 있을 때 Ctrl+D는 종료가 아닌 커서 뒤 문자를 삭제합니다.

```bash
# Claude Code가 종료되면 셸 프롬프트로 돌아옵니다.
$
```

> 💡 종료 전에 중요한 내용을 정리하고 싶다면 세션을 그냥 닫지 말고 대화 내용을 필요한 곳에 옮겨 두세요. 세션 이력은 기본 30일간 보관되며 설정으로 기간을 조정할 수 있습니다.

## 이전 세션 이어서 시작하기 — `--continue`와 `--resume`

Claude Code를 종료한 뒤 같은 주제를 계속하고 싶을 때는 새 세션을 처음부터 시작하는 대신 이전 대화를 불러올 수 있습니다.

**직전 세션 이어가기**:

```bash
claude --continue      # 가장 최근 세션을 불러와서 이어감
```

**특정 세션 선택하기**:

```bash
claude --resume        # 세션 목록을 보여줘 원하는 것을 선택
```

`--resume`을 실행하면 대화형 세션 피커(TUI)가 열립니다. 아래 키로 탐색합니다.

| 키 | 동작 |
|---|---|
| `↑` / `↓` | 세션 간 이동 |
| `Enter` | 선택한 세션 재개 |
| `Space` | 세션 내용 미리보기 |
| `/` 또는 텍스트 입력 | 검색·필터 |
| `Ctrl+A` | 전체 프로젝트 세션 표시 |
| `Esc` | 피커 종료 |

> **명칭 주의**: `--continue`(`-c`)는 이 디렉터리의 가장 최근 대화를 자동으로 불러옵니다. `--resume`(`-r`)은 세션 피커를 열어 선택합니다.

**세션 재개가 유용한 상황**:

| 상황 | 권장 방법 |
|---|---|
| 어제 하던 코드 수정을 오늘 이어서 | `--continue` |
| 일주일 전 세션의 맥락이 필요할 때 | `--resume`으로 목록 확인 |
| 현재 작업과 완전히 다른 새 주제 | 옵션 없이 `claude` (새 세션 시작) |

> 🔀 **컨텍스트 심화(연결)**: 세션 재개는 이전 대화를 컨텍스트 창에 다시 불러오는 방식입니다. 컨텍스트 창의 용량 한계와 토큰 감각은 03-7에서 다룹니다. 멀티에이전트 환경에서 세션을 어떻게 분리·관리하는지는 04장 이후에서 설명합니다.

## 정리 — 기본 리듬 확인

이 절에서 익힌 흐름을 한 줄로 정리하면 이렇습니다.

```
claude [--continue | --resume]
  → 프롬프트에 자연어 입력
  → 응답 읽기 (필요 시 Esc로 중단)
  → /exit 또는 Ctrl+D로 종료
  → 다음에 --continue로 이어가기
```

이 리듬만 몸에 익히면 다음 절부터 나오는 파일 편집·슬래시 명령어·CLI 플래그를 곧바로 활용할 수 있습니다. 이제 03-2에서는 실제 파일을 열고 수정하고 되돌리는 **편집 워크플로우**로 넘어갑니다.
